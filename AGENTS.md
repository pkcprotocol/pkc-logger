# Agent Instructions for pkc-logger

Instructions for AI agents working on this codebase.

## Workflow

- **MUST** open a pull request for every change in this repo (source, tests, docs, config, CI, `AGENTS.md`/`CLAUDE.md`) instead of pushing directly to `master`, so CodeRabbit, Claude Code review and Codex can review it.

## Bugs

- **MUST** reproduce every bug before fixing it: first add a test that fails because of the bug and watch it fail, then fix the code and watch the same test pass. This applies to bugs from issues, review comments (CodeRabbit, Claude, Codex) and ones you find yourself. If a reported bug cannot be reproduced, say so on the PR or issue instead of changing code.
